# 1. 环境搭建

## 1.1. 安装 Docker 和 Git
根据操作系统，参考官方文档下载并安装 Docker 和 Git。

- **Docker 官方安装指南**：[https://docs.docker.com/get-docker/](https://docs.docker.com/get-docker/)
- **Git 官方安装指南**：[https://git-scm.com/book/en/v2/Getting-Started-Installing-Git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)

## 1.2. 克隆 Nexent 仓库并切换分支

打开终端或命令行工具，执行以下命令：

```bash
git clone https://github.com/ModelEngine-Group/nexent.git
cd nexent/docker

# 切换到 release/v1.7.5 分支,这个版本验证过比较稳定
git fetch origin && git checkout --track origin/release/v1.7.5

cd docker

# 使用基本配置文件,执行一次完全的部署，根据网络条件,可能需要较长的时间
cp .env.example .env 
./deploy.sh

```

所有选项采用缺省配置,看到
```
🎉  Deployment completed successfully!
🌐  You can now access the application at http://localhost:3000
```
表示系统安装成功
