## 注册大模型

为防止手动在页面上配置模型太麻烦,我们提供了一个脚本 `auto-models.sh` 来自动注册模型。
本步骤注册所需的大模型到 Nexent 平台。主要通过修改 `models_config.json` 文件来配置.

### 1. 配置 `models_config.json`
编辑位于 `model_management/` 目录下的 `models_config.json` 文件，添加或修改需要注册的大模型配置。该文件定义了模型的名称、类型、API地址、密钥等信息。

为防止秘钥泄露,我们将秘钥配置写在 .env.txt 中,本次我们将全程使用硅基流动的大模型,所以只需要把硅基流动的API_KEY 配置到 .env.txt 中即可.
SILICONFLOW_API_KEY=sk-xxxx

我们选取了这4个大模型,分别是:
| 模型名称 | 类型 |
|---------|------|
| deepseek-ai/DeepSeek-V3.1-Terminus | llm |
| Qwen/Qwen2.5-32B-Instruct | llm |
| Qwen/Qwen2.5-VL-32B-Instruct | vlm |
| Qwen/Qwen3-Embedding-8B | embedding |
        

### 2. 执行注册命令
在 `model_management/` 目录下，执行以下命令来注册模型：

```bash
# 设置python3 的虚拟环境
bash setupENV.sh
# 注册模型
bash auto-models.sh
```

代码 [model_management/nexent_model_manager.py](model_management/nexent_model_manager.py)

该命令会读取 `models_config.json` 文件中的配置，并调用相应的 API 接口将模型注册到 Nexent 平台。

### 3. 验证注册结果
模型注册完成后，通过 Nexent 平台的 UI 界面(需要刷新)来确认模型是否已成功注册并可正常使用。
